# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues or pull requests.

If GitHub private vulnerability reporting is enabled for this repository, use it to contact the maintainers privately. Otherwise, contact the repository owner or maintainers privately through GitHub and include:

- A description of the affected behavior and potential impact.
- Steps to reproduce the issue, preferably in a non-production environment.
- Any relevant versions, logs, or proof-of-concept details that do not expose real user data.

Please allow maintainers reasonable time to investigate and coordinate a fix before sharing vulnerability details publicly. Do not access, alter, or disclose other users' data while investigating.

## Supported versions

No formal version support schedule is currently published. Please include the affected commit or release, if known, in a report.
